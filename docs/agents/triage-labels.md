# Triage labels

Use Matt Pocock's default label names in this repository's GitHub Issues.

| Canonical role | Tracker label | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | A maintainer must review the issue. |
| `needs-info` | `needs-info` | More information is required. |
| `ready-for-agent` | `ready-for-agent` | The work is fully specified for an agent. |
| `ready-for-human` | `ready-for-human` | The work requires a person to implement it. |
| `wontfix` | `wontfix` | The work will not be done. |

When a skill names a canonical role, use the tracker label in this table.
These names are configured; this setup does not create or apply labels on GitHub.
